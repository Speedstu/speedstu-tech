# speedstu.tech

Personal portfolio for game bots, simulation and GPU experiments.

The opening Rafale scene responds to the pointer and scroll. Its aircraft leaves the frame as the project chapters enter view. The three project chapters use local gameplay imagery and a Radeon photograph.

The site defaults to English and offers a French switch. The flight animation respects reduced motion. All content remains accessible with JavaScript disabled.

## Preview

Run `python -m http.server 8000` and open http://localhost:8000. GitHub Pages serves the `main` branch at the custom domain.
